## 4. Implementation Principles

Testable increments (each work item ends with the full suite green) · TDD red→green · no provider network I/O under the write transaction · **at most two** grouped behavior queries (O(1), never per-candidate) · no DB migration · no unrelated refactor · no magic strings · `decimal` for all scores/weights, no intermediate rounding · **no implicit score defaults** — every `GenerationCandidate` construction is explicit · AsNoTracking read-only projections in Phase 1 · Phase 2 never recomputes personalization.
